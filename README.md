# GAS-HTML-Event-Sync

This project is a fork of [GAS-ICS-Sync](https://github.com/derekantrican/GAS-ICS-Sync).

This is a standalone script (that consists of multiple files). The purpose is to parse HTML websites, and synchronize events to Google Calendar.

For setup instructions, see the following guide at the upstream repo: https://github.com/derekantrican/GAS-ICS-Sync/wiki/Setting-up-the-script-manually.
